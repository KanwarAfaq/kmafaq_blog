# SEO, indexing, GEO and AEO audit — 21 October 2026

Production site: https://kmafaq.online

## Scope and preservation

Reviewed repository routing, robots.txt, sitemaps, canonical URLs, initial HTML, metadata, structured data, index/noindex handling, and build failure behavior. Live checks covered robots, XML structure, unknown paths, and representative landing/detail pages. This is not a claim that every page is indexed or that every backlink has been inspected. Existing published slugs and article content were preserved. No mass deletion, keyword rewrite, synthetic reviews, or paid backlinks were introduced.

## Findings and changes

- Confirmed a live database mismatch: posts.updated_at does not exist. The previous generator swallowed the 400 and built only 15 public snapshots despite hundreds of published articles. Added a targeted missing-column fallback; verified the public query and rebuilt 393 snapshots using existing article data.
- Added pagination, timeouts, and fail-fast behavior on other source errors or missing production configuration, preventing silent loss of article snapshots. Local builds may reuse an explicitly available snapshot manifest.
- Removed the catch-all homepage rewrite that made arbitrary unknown paths return 200. Preserved all declared application routes and added a noindex 404 document.
- Added public HTML fallback handlers for published articles/active listings added between builds. They supply per-record canonical metadata and return 404 for missing records or 503 for unavailable data.
- Added Urdu document language/direction, restored Twitter share metadata, and skipped invalid sitemap dates. No published slugs, database rows, or stored article text were edited.

## Verification

Public anonymous posts query verified; full data-backed build generated 393 pages; snapshot/schema/language/link tests; route, 404/outage, and missing-column regression tests.

Live robots.txt and sitemap.xml were publicly reachable during the audit. The sitemap contained approximately 393 page URLs (a snapshot, not an indexed-page count). The robots file advertises `https://kmafaq.online/sitemap.xml`. A live fetch demonstrates public reachability, not proof of Googlebot ingestion. Vercel must deploy this commit before the code changes affect production.

## Content, GEO/AEO, off-page SEO, and performance

- Clear headings, crawlable original content, consistent author/publisher identity, and truthful structured data help search and answer systems understand pages. These repairs target accessibility and correctness, not guaranteed inclusion in AI answers.
- Existing indexed copy was not bulk-rewritten to remove perceived filler. Content cleanup requires evidence about indexed pages and editorial review, especially generated factual claims and citations.
- Off-page work remains an evidence-based follow-up: use the GSC Links report to inspect referring domains, keep owned profiles consistent, and earn relevant editorial references. No fabricated authority scores, link purchases, or unsolicited outreach were performed.
- Build output was checked, but a build is not a Core Web Vitals measurement. Field LCP/INP/CLS and mobile performance need CrUX/GSC data; large bundle warnings remain a separate optimization opportunity where present.
- Indexing and ranking remain Google’s decision. These fixes remove technical obstacles; they do not guarantee a position, traffic increase, or indexing date.
