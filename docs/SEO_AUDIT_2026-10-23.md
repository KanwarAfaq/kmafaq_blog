# SEO, GEO/AEO, indexing and usability audit — 23 October 2026

## Changes

- Preserved semantic article headings, citations, lists, tables and code in both build-time HTML and late-publication responses. Removed the former excerpt-style flattening and article truncation, using the existing React Markdown/GFM stack with safe URL handling. This helps crawlers and answer systems read the same substantive structure as readers.
- Marked server metadata for React Helmet adoption and removed default metadata before inserting page-specific tags. Fixed duplicate canonical/description tags, confirmed in Chromium. Added complete fallback sharing tags, publisher, image, source citation and author/date context. Did not add invented FAQs, reviews or authority claims.
- Added actual update dates to the sitemap, with a narrowly scoped fallback for databases lacking updated_at. Invalid responses, access errors and oversized output fail instead of publishing an incomplete sitemap. Existing slugs and publication status filters remain intact.
- Fixed repeated/Urdu table-of-contents anchors, excluded fenced code headings, and corrected a Markdown normalizer that split legitimate empty table cells.
- Added visible author attribution, removed repeated title text from introductions, restored one primary heading on About, Services and Contact, and prioritized the article cover image.
- Fixed the mobile drawer's containing-block problem by rendering it outside the sticky/backdrop-filter header. Added dialog semantics, keyboard focus containment, Escape, focus restoration, scroll locking and desktop-resize cleanup.
- Added skip navigation, visible focus rings, responsive reading/code/table behavior and reduced-motion handling; named pagination controls for screen readers.
- Repaired ESLint's missing JSX usage tracking and Node globals. Fixed two genuine conditional-hook defects in admin content/SEO screens, removed unused imports and obsolete suppressions. Lint now has zero errors and one existing fast-refresh warning in AuthContext.
- Added isolated fixture-backed build validation and enabled sitemap safety checks on main pushes. Fixtures are generated in a temporary checkout and never replace production public data.

## Validation

- `npm run lint`: zero errors; one pre-existing development-only fast-refresh warning.
- Chromium: 390px mobile homepage/menu and About/Services/Contact; 390px and 1440px mocked article. Verified no horizontal document overflow, one H1, one canonical/description, unique TOC targets, full-height menu, Escape, scroll lock and no browser runtime errors.
